# Product

## Register

product

## Users

Profissionais de escritório que precisam converter e traduzir documentos PDF para o formato DOCX. Estão em ambiente de trabalho, usando o app num browser desktop para realizar uma tarefa específica: obter documentos traduzíveis e editáveis rapidamente, sem perda de formatação.

## Product Purpose

O PDF Tradutor Pro permite que profissionais convertam PDFs para DOCX com tradução integrada, eliminando o trabalho manual de copiar/colar e retraduzir documentos. Sucesso é entregar um documento pronto para edição no idioma alvo em poucos cliques.

## Brand Personality

Profissional, Confiável, Moderno. Tom direto e sem rodeios — a interface comunica competência técnica. Nada lúdico ou casual.

## Anti-references

Evitar o visual "gamers" ou "dark hacker" — muito neon, contorno dramático, brilho excessivo. O tema escuro deve ser sóbrio e funcional, não estilizado. Evitar também o genérico cinza de SaaS templates Bootstrap.

## Design Principles

1. **Confiabilidade visual primeiro** — a interface deve inspirar confiança antes de impressionar. Nada de enfeites que sugiram instabilidade.
2. **Progresso visível, sempre** — o usuário nunca deve se perguntar "está funcionando?". Cada etapa do pipeline (upload → processamento → tradução → download) deve ter feedback claro.
3. **Sem surpresas** — ações são previsíveis, botões dizem exatamente o que fazem, estados de erro são explicativos.
4. **Ferramenta, não brinquedo** — evitar o lúdico. Tom sério, profissional, direto. Cada pixel serve à tarefa.

## Accessibility & Inclusion

WCAG AA como baseline. Contraste mínimo 4.5:1, foco visível em todos os elementos interativos, suporte a leitores de tela (aria-labels, roles semânticos), e preferência de movimento respeitada (prefers-reduced-motion).
